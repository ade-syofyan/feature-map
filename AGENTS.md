# Panduan Repo

- Seluruh fitur yang sudah tersedia tetap gratis. Pro dikembangkan terpisah.
- Contoh produk wajib sintetis dan mandiri. Jangan menyalin atau sekadar mengganti nama kasus pelanggan.
- Nama repo, path lokal, SHA aplikasi, aturan internal, source, hasil uji dan artifact pelanggan tidak boleh masuk Git, CI atau paket produk.
- Jalankan tes terkait sebelum commit. Perubahan perilaku mengikuti RED → GREEN → REFACTOR.
- Ikuti identitas Git dan aturan global pengguna. Jangan menulis ulang riwayat atau force-push tanpa izin eksplisit.
